# CET-4 Studio｜四级听力与精读工作台

本仓库用于开发一款 Windows 本地使用的 CET-4 学习网站，重点是**真题听力训练、精读标注、表达库和复盘**。

> **当前状态：产品需求与 UI 交互原型阶段。尚非可安装、可投入使用的完整软件。** UI 原型包含演示数据，不代表功能已实现。

## 交付给 DSH 的资料

- [详细开发任务书](docs/DSH_IMPLEMENTATION_SPEC_v1.md)：完整产品目标、听力训练流程、混合文件导入、自由标注、数据模型、API、任务优先级、测试与验收标准。
- [UI 交互原型](design/UI_INTERACTIVE_PROTOTYPE_v1.html)：独立 HTML 文件，可下载后在浏览器中打开，作为 UI/交互参考（不是生产环境应用）。

## 直接下载

通过 GitHub 页面右上方 **Code → Download ZIP** 下载仓库中全部资料。

## 开发优先级

1. 可运行的本地工程与混合资料导入。
2. 真题听力工作台：首听、答题、A-B 循环、倍速、隐藏原文、复听与错误原因。
3. 英语精读：鼠标标注单词、短语和句式，保存出处、释义和笔记。
4. 表达库：去重、复习、筛选、导出。
5. 本地备份/恢复和自动化验收测试。

请以任务书中的具体验收标准为准。**不要把按钮占位、演示统计数据或无法保存的数据标记为开发完成。**
